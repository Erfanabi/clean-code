# Playground — فضای کار تو

کد تمرین‌ها را اینجا بنویس. ساختار پیشنهادی:

</div>

```text
playground/<module>/<lesson>/<level>-<number>.ts
playground/<module>/<lesson>/<level>-<number>.test.ts
```

<div dir="rtl">

مثال: `playground/00-foundations/01-what-is-clean-code/intermediate-1.ts`

همه‌ی فایل‌های `.ts` اینجا با TypeScript strict بررسی می‌شوند و همه‌ی `*.test.ts`ها با `npm test` اجرا می‌شوند. راهنمای کامل در [exercises/README.md](../exercises/README.md).

</div>
