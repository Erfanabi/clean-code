# پروژه‌های واقعی (ماژول ۱۳)

سه پروژه‌ی کامل که همه‌ی آموخته‌های بوت‌کمپ را به کار می‌گیرند. هر پروژه وقتی به ماژول ۱۳ برسیم ساخته می‌شود و شامل این بخش‌هاست: نیازمندی‌ها، معماری، ساختار پوشه‌ها، مراحل پیاده‌سازی، ملاحظات Clean Code، تمرین‌ها، تست‌های واحد، تسک‌های Refactoring و چک‌لیست Code Review.

| پروژه | پوشه | تمرکز اصلی |
|---|---|---|
| سیستم مدیریت سفارش فروشگاهی | `ecommerce-order-management/` | مدل دامنه، Value Object، قواعد قیمت‌گذاری، Use Case |
| سیستم مدیریت وظایف | `task-management/` | State Machine، Discriminated Union، تست‌پذیری |
| سرویس API با Node.js و TypeScript | `api-service/` | لایه‌بندی، مدیریت متمرکز خطا، Repository، تست یکپارچگی |
