# دوره‌ها و تمرین‌گاه‌های پیشنهادی

این بوت‌کمپ به‌تنهایی کامل است، اما تمرین بیشتر و دیدن توضیح از زاویه‌ای دیگر همیشه کمک می‌کند. در این فهرست فقط منابعی آمده‌اند که شناخته‌شده و پایدارند. قیمت و محتوای دوره‌های پولی ممکن است تغییر کند؛ قبل از خرید، صفحه‌ی دوره را بررسی کن.

## تمرین‌گاه‌ها (رایگان)

| منبع | چرا | چه زمانی |
|---|---|---|
| [Exercism — TypeScript Track](https://exercism.org/tracks/typescript) | تمرین‌های کوتاه با امکان دریافت بازخورد از منتورها؛ بعد از حل، راه‌حل‌های دیگران را بخوان و مقایسه کن — بهترین تمرین برای «خواندن کد» | از ماژول ۰۱ به بعد، هفته‌ای ۲ تا ۳ تمرین |
| [Type Challenges](https://github.com/type-challenges/type-challenges) | چالش‌های سیستم نوع TypeScript از آسان تا بسیار سخت | هم‌زمان با ماژول ۰۶؛ فقط سطوح easy و medium |
| [Refactoring Guru](https://refactoring.guru/) | توضیح تصویری Smellها، تکنیک‌های Refactoring و الگوهای طراحی | ماژول‌های ۰۰، ۱۰ و ۱۱ |

## دوره‌ها (پولی)

| منبع | چرا | چه زمانی |
|---|---|---|
| [Total TypeScript — Matt Pocock](https://www.totaltypescript.com/) | دوره‌های عمیق و تمرین‌محور TypeScript؛ بخشی از محتوا رایگان است | ماژول ۰۶ |
| [Testing JavaScript — Kent C. Dodds](https://testingjavascript.com/) | تست در JavaScript و React با دیدگاه «تست رفتار، نه پیاده‌سازی» | ماژول ۱۲ |
| [Clean Coders — Robert C. Martin](https://cleancoders.com/) | ویدیوهای خود نویسنده‌ی Clean Code؛ مثال‌ها به Java | اختیاری، برای ماژول‌های ۰۰ تا ۰۷ |

## پیشنهاد ترتیب

1. از ماژول ۰۱ به بعد، Exercism را به‌عنوان تمرین جانبی شروع کن.
2. در ماژول ۰۶، Type Challenges و در صورت تمایل Total TypeScript.
3. در ماژول ۱۲، Testing JavaScript.
4. Refactoring Guru را همیشه باز نگه دار؛ مرجع سریع توست.
