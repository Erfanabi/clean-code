# مقاله‌های پیشنهادی

مقاله‌ها کوتاه‌تر از کتاب‌اند و برای مرور سریع یک مفهوم یا دیدن یک دیدگاه خاص عالی‌اند. فهرست زیر بر اساس ماژول مرتب شده است. همه‌ی لینک‌ها از منابع شناخته‌شده‌اند؛ اگر لینکی از دسترس خارج شد، عنوان مقاله را در همان سایت جست‌وجو کن.

## مقاله‌های Martin Fowler

سایت martinfowler.com یکی از معتبرترین منابع مهندسی نرم‌افزار است. بخش «bliki» آن یادداشت‌های کوتاه درباره‌ی یک مفهوم است.

| مقاله | موضوع | ماژول |
|---|---|---|
| [Is High Quality Software Worth the Cost?](https://martinfowler.com/articles/is-quality-worth-cost.html) | چرا کیفیت داخلی کد در بلندمدت هزینه را کم می‌کند | ۰۰ |
| [Design Stamina Hypothesis](https://martinfowler.com/bliki/DesignStaminaHypothesis.html) | نقطه‌ای که طراحی خوب جبران هزینه‌اش را می‌کند | ۰۰ |
| [Technical Debt](https://martinfowler.com/bliki/TechnicalDebt.html) | تعریف بدهی فنی و «بهره»ی آن | ۰۰ |
| [Technical Debt Quadrant](https://martinfowler.com/bliki/TechnicalDebtQuadrant.html) | چهار نوع بدهی فنی: آگاهانه/ناآگاهانه، محتاطانه/بی‌پروا | ۰۰ |
| [Code Smell](https://martinfowler.com/bliki/CodeSmell.html) | تعریف دقیق Code Smell | ۰۰ |
| [Opportunistic Refactoring](https://martinfowler.com/bliki/OpportunisticRefactoring.html) | بازآرایی هم‌زمان با کار روزمره؛ هم‌خانواده‌ی Boy Scout Rule | ۰۰، ۱۱ |
| [Two Hard Things](https://martinfowler.com/bliki/TwoHardThings.html) | نقل‌قول معروف درباره‌ی سختی نام‌گذاری | ۰۱ |
| [Function Length](https://martinfowler.com/bliki/FunctionLength.html) | طول مناسب تابع: فاصله‌ی بین نیت و پیاده‌سازی | ۰۲ |
| [Command Query Separation](https://martinfowler.com/bliki/CommandQuerySeparation.html) | جداسازی Command و Query | ۰۲ |
| [Value Object](https://martinfowler.com/bliki/ValueObject.html) | تعریف Value Object | ۰۵ |
| [Anemic Domain Model](https://martinfowler.com/bliki/AnemicDomainModel.html) | مدل دامنه‌ی بی‌رفتار و مشکلاتش | ۰۵ |

| [Inversion of Control Containers and the Dependency Injection pattern](https://martinfowler.com/articles/injection.html) | مقاله‌ی پایه‌ای DI | ۰۹، ۱۰ |
| [Mocks Aren't Stubs](https://martinfowler.com/articles/mocksArentStubs.html) | تفاوت Mock و Stub و دو مکتب تست | ۱۲ |
| [The Practical Test Pyramid](https://martinfowler.com/articles/practical-test-pyramid.html) | هرم تست در عمل | ۱۲ |
