# تمرین‌ها

هر درس پنج تمرین دارد: **۲ مبتدی، ۲ متوسط و ۱ پیشرفته**، در سه فایل جداگانه:

| سطح | مسیر | هدف |
|---|---|---|
| مبتدی | `exercises/beginner/<module>/<lesson>.md` | تشخیص و به‌کارگیری مستقیم مفهوم |
| متوسط | `exercises/intermediate/<module>/<lesson>.md` | بازآرایی کد واقعی و نوشتن تست |
| پیشرفته | `exercises/advanced/<module>/<lesson>.md` | طراحی، تصمیم‌گیری و توضیح Trade-off |

## کد را کجا بنویسم؟

کد خودت را در پوشه‌ی `playground/` بنویس، با این ساختار:

</div>

```text
playground/
└── 00-foundations/
    └── 01-what-is-clean-code/
        ├── intermediate-1.ts
        └── intermediate-1.test.ts
```

<div dir="rtl">

پوشه‌ی `playground` در `tsconfig.json` و `vitest.config.ts` ثبت شده است؛ پس `npm run check` کد و تست‌های تو را هم بررسی می‌کند.

## روند کار

1. صورت تمرین را بخوان و **اول خودت** حل کن.
2. اگر گیر کردی، دستور `راهنمایی` را بفرست؛ یک سرنخ می‌گیری، نه جواب.
3. وقتی تمام شد، دستور `بررسی کد` را بفرست (و بگو کدام تمرین).
4. بعد از بررسی، اگر خواستی دستور `راه حل` را بفرست تا راه‌حل مرجع در `solutions/` نوشته شود.

برای جواب‌های متنی (مثلاً «Smellها را نام ببر») یک فایل `answers.md` در همان پوشه‌ی `playground` بنویس یا جوابت را مستقیم در گفتگو بفرست.
