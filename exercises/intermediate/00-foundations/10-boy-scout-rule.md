## تمرین ۱: جریان سه Commitی

گزارش باگ: «وقتی کاربر کد تخفیف را با حروف کوچک وارد می‌کند (`off10`)، تخفیف اعمال نمی‌شود.»

</div>

```typescript
export function apply(c: any[], code: string) {
  var s = 0;
  for (var i = 0; i < c.length; i++) s = s + c[i].p * c[i].n;
  if (code == 'OFF10') s = s - s / 10;
  if (code == 'WELCOME') s = s - 50000;
  // if (code == 'YALDA') s = s * 0.7;
  return s < 0 ? 0 : s;
}
```

<div dir="rtl">

**خواسته:** دقیقاً مثل درس، در سه گام جدا کار کن:

1. **`test:`** تستی بنویس که باگ را نشان دهد و **شکست بخورد**. (یک تست برای رفتار فعلی درست هم اضافه کن.)
2. **`refactor:`** بهبودهای Boy Scout بدون تغییر رفتار. همه‌ی تست‌ها به جز تست باگ باید سبز بمانند.
3. **`fix:`** کمترین تغییر ممکن برای رفع باگ. حالا همه‌ی تست‌ها سبز.

اگر Git داری، سه Commit واقعی بزن و خروجی `git log --oneline` را بفرست. اگر نه، سه فایل `step-1.ts`، `step-2.ts`، `step-3.ts` بساز.

**سؤال:** آیا `trim()` کردن کد تخفیف (فاصله‌ی اضافه) جزو همین `fix` است یا یک تغییر رفتاری جدا؟ دلیلت را بنویس.
