# تمرین‌های مبتدی — درس ۱: Clean Code چیست؟

> درس مرتبط: [Clean Code چیست؟](../../../docs/00-foundations/01-what-is-clean-code.md)

## تمرین ۱: شکار مشکلات

کد زیر یک دمای سلسیوس را به فارنهایت تبدیل می‌کند و وضعیت هوا را برمی‌گرداند.

</div>

```javascript
function f(a, b) {
  var x = a * 1.8 + 32;
  if (b == true) console.log(x);
  if (x > 86) return 'h';
  else if (x < 50) return 'c';
  else return 'n';
}
```

<div dir="rtl">

**خواسته:**

1. حداقل **۶ مشکل** این کد را فهرست کن.
2. برای هر مشکل بگو کدام بخش از تعریف Clean Code (سریع خواندن، درست فهمیدن، با اطمینان تغییر دادن) را نقض می‌کند.

**معیار پذیرش:** هر مشکل یک «چرا» دارد، نه فقط «این بد است».

## تمرین ۲: فقط نام‌گذاری

همان کد بالا را **بدون تغییر منطق** فقط با تغییر نام‌ها، ثابت‌ها و حذف پارامتر `b` بازنویسی کن (TypeScript).

**راهنمای شروع:** نتیجه باید بتواند در یک جمله‌ی انگلیسی خوانده شود؛ مثلاً `describeWeather(celsius)`.

**معیار پذیرش:**

- هیچ نام تک‌حرفی باقی نمانده باشد.
- اعداد `1.8`، `32`، `86` و `50` نام داشته باشند.
- خروجی‌های `'h'`، `'c'`، `'n'` با یک Union Type گویا جایگزین شده باشند.
- `console.log` حذف شده باشد (و بنویس چرا).
