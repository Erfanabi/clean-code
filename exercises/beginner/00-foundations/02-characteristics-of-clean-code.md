# تمرین‌های مبتدی — درس ۲: ویژگی‌های کد تمیز

> درس مرتبط: [ویژگی‌های کد تمیز](../../../docs/00-foundations/02-characteristics-of-clean-code.md)

## تمرین ۱: کارنامه‌ی ده ویژگی

</div>

```javascript
let cache = {};
function getUserName(id) {
  if (cache[id]) return cache[id];
  const u = db.find(id);
  cache[id] = u.first + ' ' + u.last;
  db.update(id, { lastSeen: Date.now() });
  return cache[id];
}
```

<div dir="rtl">

**خواسته:** جدول ده ویژگی درس را برای این کد پر کن: برای هر ویژگی ✅، ⚠️ یا ❌ بگذار و یک جمله توضیح بنویس.

**نکته‌ی کلیدی:** به نام تابع (`get...`) و کاری که واقعاً انجام می‌دهد دقت کن. همچنین بپرس: اگر کاربر وجود نداشته باشد چه می‌شود؟

## تمرین ۲: ترتیب قواعد Kent Beck

سه نسخه از یک تابع داری:

- **نسخه‌ی A:** خوانا، بدون تکرار، ولی برای ورودی خالی خطا می‌دهد.
- **نسخه‌ی B:** همه‌ی تست‌ها پاس می‌شوند، خوانا، ولی دو خط تکراری دارد.
- **نسخه‌ی C:** همه‌ی تست‌ها پاس می‌شوند، بدون تکرار، ولی برای حذف تکرار یک تابع عمومی با ۴ پارامتر Boolean ساخته که فهمیدنش سخت است.

**خواسته:** این سه نسخه را از بهترین به بدترین رتبه‌بندی کن و با استناد به **ترتیب** چهار قاعده‌ی Kent Beck توضیح بده.
