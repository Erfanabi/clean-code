# تمرین‌های مبتدی — درس ۵: نگهداشت‌پذیری

> درس مرتبط: [نگهداشت‌پذیری](../../../docs/00-foundations/05-maintainability.md)

## تمرین ۱: سه نشانه‌ی پیچیدگی

برای هر سناریو بگو کدام نشانه (Change Amplification، Cognitive Load یا Unknown Unknowns) غالب است و چرا:

1. رنگ اصلی برند (`#1a73e8`) در ۳۲ فایل CSS و TSX به‌صورت مستقیم نوشته شده است.
2. برای اضافه کردن یک فیلد به فرم ثبت‌نام، باید بدانی که هوک `useFormSteps` ترتیب فیلدها را از روی **ترتیب کلیدهای یک Object** استنتاج می‌کند.
3. یک توسعه‌دهنده فرمت تاریخ را در API عوض کرد؛ همه چیز کار کرد؛ دو هفته بعد گزارش ماهانه‌ی مالی که در یک Cron Job جداگانه همان API را پارس می‌کرد، خالی بیرون آمد.
4. هر بار که نرخ کمیسیون فروشندگان تغییر می‌کند، باید فایل‌های Backend، اپ ادمین و اپ فروشندگان را تغییر دهی.

## تمرین ۲: تغییر محتمل بعدی

برای هر سیستم، **دو** تغییر محتمل و **یک** تغییر نامحتمل بنویس. سپس بگو طراحی باید برای کدام آماده باشد.

1. فرم پرداخت یک فروشگاه اینترنتی ایرانی
2. سیستم نوبت‌دهی یک مطب
3. صفحه‌ی پروفایل کاربر در یک شبکه‌ی اجتماعی
