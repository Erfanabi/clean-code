# تمرین پیشرفته — درس ۶: بدهی فنی

> درس مرتبط: [بدهی فنی](../../../docs/00-foundations/06-technical-debt.md)

## تمرین: ابزار تحلیل Hotspot

یک اسکریپت Node.js + TypeScript بنویس که Hotspotهای بدهی فنی یک مخزن Git را پیدا کند.

**ورودی:** مسیر یک مخزن Git و یک بازه‌ی زمانی (مثلاً ۹۰ روز).

**خروجی:** جدولی از فایل‌ها، مرتب‌شده بر اساس امتیاز Hotspot:

| فایل | تعداد تغییر (Churn) | تعداد خطوط | امتیاز |
|---|---|---|---|

که در آن «امتیاز = Churn × تعداد خطوط» (یک تقریب ساده برای «پرتغییر × بزرگ»).

**خواسته:**

1. منطق را به سه بخش **جدا** تقسیم کن:
   - جمع‌آوری داده (اجرای `git log` با `node:child_process` و خواندن فایل‌ها)
   - محاسبه (توابع Pure که آرایه‌ای از `{ path, churn, lines }` می‌گیرند و امتیاز و ترتیب را برمی‌گردانند)
   - نمایش (تبدیل به جدول متنی یا Markdown)
2. بخش محاسبه را کامل تست کن، **بدون** اجرای Git واقعی.
3. فایل‌های غیرکد (مثلاً `package-lock.json` و `.md`) را با یک فهرست قابل تنظیم کنار بگذار.
4. ابزار را روی یک پروژه‌ی واقعی خودت اجرا کن و ۵ Hotspot اول را با یک جمله تحلیل برای هر کدام گزارش بده.
5. محدودیت این معیار را بنویس: چه چیزی را **نمی‌سنجد**؟

**معیار پذیرش:** بخش محاسبه بدون هیچ import از `node:*` است؛ `npm run check` سبز.
