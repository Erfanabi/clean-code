> درس مرتبط: [ویژگی‌های کد تمیز](../../../docs/00-foundations/02-characteristics-of-clean-code.md)

## تمرین: اعتبارسنجی و ثبت سفارش

یک ماژول ثبت سفارش در TypeScript بساز که هر ده ویژگی درس را رعایت کند.

**قواعد کسب‌وکار:**

- سفارش حداقل یک قلم دارد و حداکثر ۲۰ قلم.
- تعداد هر قلم عدد صحیح بین ۱ تا ۱۰ است.
- آدرس ارسال باید کد پستی ۱۰ رقمی داشته باشد.
- اگر روش پرداخت «پرداخت در محل» باشد، مبلغ کل نباید بیشتر از ۵ میلیون تومان باشد.
- بعد از ثبت موفق: سفارش ذخیره، موجودی انبار کم و پیامک تأیید ارسال می‌شود.

**خواسته:**

1. `validateOrder(input): ValidationResult` — Pure، همه‌ی خطاها را با هم برگرداند (نه فقط اولی).
2. `placeOrder(input, deps)` — وابستگی‌ها (`OrderRepository`، `Inventory`، `SmsSender`) صریح.
3. تصمیم بگیر و مستند کن: اگر ذخیره موفق شد ولی ارسال پیامک شکست خورد، چه اتفاقی بیفتد؟ (این یک سؤال طراحی است؛ جواب درست واحد ندارد، ولی تصمیم باید صریح باشد.)
4. تست‌ها: حداقل ۱۰ تست شامل همه‌ی مرزها و سناریوی شکست پیامک.
5. یک جدول ده ویژگی برای کد خودت پر کن.

**معیار پذیرش:** `npm run check` سبز، بدون `any`، بدون Mutation ورودی، و تصمیم سؤال ۳ در یک کامنت یا README کوتاه.
