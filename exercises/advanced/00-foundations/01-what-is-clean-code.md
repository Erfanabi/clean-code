# تمرین پیشرفته — درس ۱: Clean Code چیست؟

> درس مرتبط: [Clean Code چیست؟](../../../docs/00-foundations/01-what-is-clean-code.md)

## تمرین: پرونده‌ی «ارزش Clean Code» برای مدیر محصول

مدیر محصول می‌گوید: «تیم دو روز برای تمیز کردن ماژول فاکتور وقت خواسته. کد که کار می‌کند! چرا باید این هزینه را بدهیم؟»

### بخش الف: کد

کد زیر ماژول فاکتور فعلی است:

</div>

```typescript
export function inv(o: any) {
  let s = 0;
  for (const i of o.lines) {
    let p = i.price * i.q;
    if (i.cat == 'book') p = p * 0.95;
    if (i.cat == 'food') p = p;
    else p = p * 1.1;
    s += p;
  }
  if (o.c && o.c.startsWith('VIP')) s = s * 0.9;
  if (s > 2000000) s = s - 100000;
  console.log('invoice', o.id, s);
  return { id: o.id, total: Math.round(s), date: new Date().toISOString() };
}
```

<div dir="rtl">

1. کد را در TypeScript بازآرایی کن. همه‌ی قواعد کسب‌وکار باید **نام‌دار و صریح** شوند.
2. یک باگ یا ابهام کسب‌وکاری در کد اصلی پیدا کن (راهنمایی: به ترتیب اعمال تخفیف کتاب و مالیات، و به خط `p = p` دقت کن) و آن را به‌صورت **سؤال از مدیر محصول** بنویس، نه اینکه خودسرانه تغییرش دهی.
3. `new Date()` را طوری مدیریت کن که تابع تست‌پذیر شود.
4. تست‌های هم‌رفتاری بنویس که ثابت کند رفتار تغییر نکرده است.

### بخش ب: متن برای مدیر

یک متن فارسی حداکثر ۲۰۰ کلمه‌ای بنویس که بدون اصطلاحات فنی، ارزش این دو روز را با زبان **زمان، هزینه و ریسک** توضیح دهد.

**معیار پذیرش:**

- تست‌ها پاس می‌شوند و `npm run check` بدون خطاست.
- متن مدیر حداقل یک عدد یا تخمین مشخص دارد.
- سؤال کسب‌وکاری دقیق و قابل پاسخ است.
