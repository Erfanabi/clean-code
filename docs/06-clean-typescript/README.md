# ماژول ۰۶: TypeScript تمیز (Clean TypeScript)

## هدف این ماژول

استفاده از سیستم نوع TypeScript برای اینکه «حالت‌های نامعتبر غیرقابل‌نمایش» شوند: strict mode، unknown، Discriminated Union، Generic، Type Guard و سازمان‌دهی Typeها.

## پیش‌نیاز

تکمیل ماژول ۰۵: اشیا و ساختمان داده.
