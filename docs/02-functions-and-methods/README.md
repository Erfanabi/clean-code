# ماژول ۰۲: توابع و متدها (Functions and Methods)

## هدف این ماژول

تابع کوچک‌ترین واحد سازمان‌دهی رفتار است. این ماژول یاد می‌دهد توابع کوچک، تک‌مسئولیتی، قابل‌پیش‌بینی و بدون Side Effect پنهان بنویسیم و کنترل جریان را ساده کنیم.

## پیش‌نیاز

تکمیل ماژول ۰۱: نام‌گذاری و سازمان‌دهی کد.

## زمان تخمینی

۲ هفته
