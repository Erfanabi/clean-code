# ماژول ۱۰: الگوهای طراحی (Design Patterns)

## هدف این ماژول

هر الگو به‌عنوان «راه‌حل یک مسئله‌ی تکرارشونده»: مسئله، راه‌حل، پیاده‌سازی مدرن در TypeScript و — به همان اندازه مهم — زمانی که نباید از آن استفاده کرد.

## پیش‌نیاز

تکمیل ماژول ۰۹: معماری تمیز.

## ساختار هر درس

هر درس طبق استاندارد بوت‌کمپ شامل این بخش‌هاست: توضیح مفهوم، توضیح فنی و Trade-offها، کد بد در JavaScript و TypeScript، تحلیل خط‌به‌خط، پیاده‌سازی تمیز، مقایسه، سناریوهای واقعی، اشتباهات رایج، دیدگاه Code Review، تمرین (در فایل جداگانه) و جمع‌بندی با چک‌لیست خودارزیابی.
