# ماژول ۰۸: اصول طراحی نرم‌افزار (Software Design Principles)

## هدف این ماژول

اصول کلی‌تر از SOLID که در هر زبان و پارادایمی کاربرد دارند؛ و مهم‌تر از آن، تنش‌های بین این اصول (مثلاً DRY در برابر Coupling) و نحوه‌ی تصمیم‌گیری.

## پیش‌نیاز

تکمیل ماژول ۰۷: اصول SOLID.

## زمان تخمینی

۱.۵ هفته

هر درس طبق استاندارد بوت‌کمپ شامل این بخش‌هاست: توضیح مفهوم، توضیح فنی و Trade-offها، کد بد در JavaScript و TypeScript، تحلیل خط‌به‌خط، پیاده‌سازی تمیز، مقایسه، سناریوهای واقعی، اشتباهات رایج، دیدگاه Code Review، تمرین (در فایل جداگانه) و جمع‌بندی با چک‌لیست خودارزیابی.
