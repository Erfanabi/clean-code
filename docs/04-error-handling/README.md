# ماژول ۰۴: مدیریت خطا (Error Handling)

## هدف این ماژول

خطا بخشی از منطق برنامه است، نه استثنا از آن. این ماژول یاد می‌دهد خطاها را دسته‌بندی، منتشر و در یک نقطه‌ی مرکزی مدیریت کنیم بدون اینکه منطق اصلی کثیف شود.
