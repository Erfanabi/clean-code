# ماژول ۰۱: نام‌گذاری و سازمان‌دهی کد (Naming and Code Organization)

## هدف این ماژول

نام‌ها بیشترین بخش «خواندن» کد را تشکیل می‌دهند. این ماژول یاد می‌دهد چطور نام‌هایی بسازیم که نیت را آشکار کنند و فایل‌ها و ماژول‌ها را طوری بچینیم که پیدا کردن و تغییر دادن کد آسان باشد.

## پیش‌نیاز

تکمیل ماژول ۰۰: مبانی Clean Code.

## زمان تخمینی

۱.۵ هفته
