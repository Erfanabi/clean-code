# ماژول ۰۹: معماری تمیز (Clean Architecture)

## هدف این ماژول

از کد تمیز به سیستم تمیز: لایه‌ها، قانون وابستگی، Use Case، Repository، Dependency Injection و Hexagonal Architecture در پروژه‌های Node.js و Next.js.

## پیش‌نیاز

تکمیل ماژول ۰۸: اصول طراحی نرم‌افزار.
