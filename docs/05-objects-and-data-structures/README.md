# ماژول ۰۵: اشیا و ساختمان داده (Objects and Data Structures)

## هدف این ماژول

تفاوت «شیء» و «داده‌ی خام»، کپسوله‌سازی، تغییرناپذیری، Value Object و مدل دامنه؛ و اینکه چطور Cohesion بالا و Coupling پایین را در سطح داده‌ها بسازیم.
