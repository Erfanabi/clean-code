# ماژول ۱۲: تست و Clean Code (Testing and Clean Code)

## هدف این ماژول

کد تمیز کدی است که تست‌کردنش آسان باشد، و تست تمیز مستندات زنده‌ی سیستم است. همه‌ی مثال‌ها با Vitest.

تکمیل ماژول ۱۱: بازآرایی کد.
